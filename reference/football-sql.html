SQL for football records

Table: named collection of records. Row: one record. Column: one named field. Define the row's meaning before counting.

SELECT COUNT(*) FROM corners;
SELECT COUNT(*) FROM corners WHERE period = 1;
  • SELECT: request results.
  • FROM: choose the source table.
  • WHERE: filter rows before aggregation.
  • COUNT(*): count rows.
  • SUM(column): add values.
  • GROUP BY: calculate per-group summaries.
  • ORDER BY: specify result order.
  • LIMIT: restrict returned rows.

For one row per corner, COUNT(*) counts deliveries. SUM(has_phase_shot) counts corners with any shot. SUM(phase_shots) counts shots. Keep zero-shot deliveries in the rate denominator.

Use parameter binding for data values, decimal arithmetic for rates and an undefined result for zero exposure. Do not assume inherent table ordering. A primary key guards row identity.
