Football analyst training · Recruitment phase · Lesson 79

Connect the recorded events.

Data: FIFA Women's World Cup, 2019 — StatsBomb competition 72, season 30.
Read: Soccermatics Lesson 3 — Statistical scouting → Context: what to measure.
Technical definition: StatsBomb specification → related_events and Pass outcome.

A possession label describes a passage of play. An event link connects specific recorded actions. Now we use those links to inspect opponent passes associated with a pressure.

How the join works

Pressure event
  → related_events contains a pass ID
  → find that ID in the same match
  → check it is an opponent Pass
  → read the recorded pass outcome

We use IDs supplied by the provider, not whichever pass happens to be closest in time. A link describes an association; it does not prove that the pressure caused the pass outcome.

A real recorded example

France–South Korea, 7 June 2019, first half:

16:03.342   Majri pressure
     linked to
16:04.526   Hye-Ri Kim pass → Incomplete

Pressure ID: fb96a1cf-d47a-46cd-a0da-82ab6288aba7. Pass ID: f9fe2285-e271-4884-b807-809131dd96f1. The provider links these events in both directions. We have not watched footage or established why the pass was incomplete.

The completed assignment

Unique linked opponent passes:
Bronze: 28 → 19 completed, 8 not completed, 1 unclear
Majri:   7 →  4 completed, 3 not completed, 0 unclear

These passes come from 28 of Bronze's 102 pressures and 7 of Majri's 61 pressures. Other pressures may link to carries or different actions, or have no recorded link. They are not automatically failed pressures.

We processed all 35 profiles and retained all 2,034 original pressure rows. The join produced 549 opponent-pass relationships. If multiple pressures by the same player link to one pass, that pass counts once in her outcome totals. Across different players, the same pass can still appear again.

Keep the denominator honest

Majri's three non-completed passes belong to a subset of seven linked passes—not all 61 pressures.

Bronze's unclear pass has an Unknown outcome label and stays outside any assessable-pass percentage. Restart deliveries can remain: this question uses direct links rather than our earlier non-restart passing filter. We audit reciprocal references and stop on missing/duplicate IDs.

Practice: two pressures by the same player link to the same incomplete pass. How many unique incomplete passes should her report count?

One. There are two pressure–pass relationships but one pass outcome. This is the same duplicate-inflation problem we studied with table joins.

A completed pass could be backwards and useful to the defending team. An incomplete pass could result from something other than pressure. These small selected subsets are not player success grades or official Pressure Regains.
