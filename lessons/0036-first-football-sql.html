Football analyst training · SQL block · Lesson 54

Ask a database a football question.

A database stores structured records. SQL is a language for asking it questions. We now store our France corner data in a local SQLite database.

One row, one corner

The corners table contains 45 rows. Each row is one recorded delivery, with columns such as opponent, half, time and phase-shot count. A corner with two shots still occupies one row.

Your first query

SELECT COUNT(*)
FROM corners;

Read it as: “From the corners table, count all rows.” The answer is 45.

Add a filter

SELECT COUNT(*)
FROM corners
WHERE period IN (3, 4);

WHERE keeps only matching rows. Periods 3 and 4 are extra time. The answer is 3.

The database contains the same football evidence. SQL gives us another way to retrieve, filter and summarize it.
