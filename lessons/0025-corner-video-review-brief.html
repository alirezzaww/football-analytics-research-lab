Use the data to choose what to inspect.

We prepared six corner examples across all five opponents, with a delivery associated with a shot and one without for each endpoint zone.

Completed assignment

Open the generated review brief. It contains opponent/date, match clock, period, taker, exact event ID, endpoint zone and observation questions. This prepares a practical next step for a performance analyst.

The data identifies useful examples. Video would help check first contact, attacking control, movement and marking.

Keep observation separate from interpretation

“The defender heads the ball away” would be an observable action if visible. “The routine was poorly designed” is an interpretation needing further evidence. Use unknown when footage is unclear or unavailable.

Know how the examples were selected

We deliberately cover zones and outcomes, preferring different matches. That makes a useful review queue, but not a representative sample. Calculate team rates from all 45 deliveries, not these six chosen examples.

Locate an event correctly

Match-clock labels are not video-file timestamps. Use the opponent, date and half as well as the clock, then record the actual video reference once found.
