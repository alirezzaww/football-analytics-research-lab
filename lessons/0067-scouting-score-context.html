Match the actions to the time available.

Data: FIFA Women's World Cup, 2019 — StatsBomb competition 72, season 30.
Read: Soccermatics Lesson 3 — Statistical scouting → Normalisation.
SQL: SQLite expressions → CASE and NULLIF. Our score-context extension is a custom assignment.

We previously counted actions while a team was leading, drawing or trailing. Now we also calculate how long the player was registered on the pitch in each state.

The completed assignment

For Bronze's fixed-rule forward completions:

State      Actions   Minutes      Actions per 90
Leading       19      386.71          4.42
Drawing        8      137.59          5.23
Trailing       7      166.88          3.78

Rates use unrounded milliseconds. The counts still sum to 34 forward completions and the time still sums to her original 691.18 registered minutes.

Bronze had more qualifying forward passes while leading, but a higher rate while drawing. She spent much longer leading.

The calculation

Actions in that state ÷ minutes in that state ×90

Using all her minutes for each state's count would mix the denominators. We partition both actions and time, then pool across her included matches before division.

How we split the time

We reconstruct the score from recorded goals and own goals, excluding shootouts. At each logged goal timestamp, the time state changes. An action receives the score immediately before it according to event index. Logged goal-event times approximate the actual score-change instant; these are event-data conventions, not frame-accurate video measurements.

Added/extra time remains included and halftime gaps stay excluded, following our existing registered-time method. Reconstructed final scores match metadata for all 50 included fixtures. All 435 player–match–state rows reconcile to the original 145 match rows and 35 profiles.

Practice: if a player never played while trailing, should her trailing rate be 0?

No. With zero time in that state, the rate is undefined. Zero activity in a state with positive time is different from having no exposure to that state.

What the result does not explain

It does not prove that drawing caused Bronze to advance the ball more often. Different opponents, match phases, possession and roles can also differ between these states. A large rate based on little time needs careful interpretation; check both the action count and the minutes.
