## Role direction and evidence from employers

Keep football data analysis as the primary learning direction while building football reporting and video-review skills. This is a training focus, not a claim of current readiness. Football performance analysis, recruitment/video analysis and data analysis have overlapping but different requirements.

Employer examples reviewed on 4 November 2026:

- [Pluto Data Analytics careers](https://www.plutodata.co.uk/careers): the Club Analyst profile describes SQL extraction, reporting, communication and club experience; its data role profiles also mention Python. These are useful skill signals. The page's explicit current-hiring section listed Software Engineer when reviewed; do not treat every role description on the page as a verified open vacancy. Its stated hybrid arrangement includes at least two office days weekly.
- [Newcastle Scouting Analyst (Africa)](https://careers.newcastleunited.com/job/scouting-analyst-africa-6063955): an official role example combining video, player reports and recruitment knowledge. **Expired 2 November 2026**, before this review; this is a requirements reference, not an application lead.

It is a **lead role**, not an entry-level recommendation. Availability must be rechecked before considering an application.

These few sources illustrate requirements, not a complete labour-market survey or a personalized suitable-job shortlist. No employer has been contacted and no applications have been submitted.

## Next employment milestones

1. **Explain and reproduce one case study.** Alireza should run it, explain its denominator and one finding, and make a small documented change without having the assistant perform every step. Record that evidence after completion.
2. **Develop the practical SQL block.** Lessons 54–58 implement guided table/load/query, relational joins, opponent and match-phase comparisons, and a player report with group filtering on existing corner data. Independently reproduce and explain them, then extend to match/team/player aggregates and more database tasks. A first implementation is not completed SQL competence.
3. **Complete a video observation exercise when footage is available.** Use the sourced six-event review brief, record actual video references and observable actions. The existing queue is preparation only.
4. **Build an independent second case study.** Choose a bounded question on unfamiliar matches, define rules, implement the core analysis, and write a concise audience-focused report. Preserve assistant contribution honestly.
5. **Prepare targeted application materials.** Use an accurate CV and two defensible work samples, plus a short explanation of methods and findings. Tailor to a verified role rather than claiming every analyst title fits.
6. **Run an active job search alongside learning.** Look for junior/assistant data analyst, internships, suitable provider roles and club opportunities with supervision. Verify duties, experience, compensation, location, work rights/sponsorship and deadline for each lead. An opportunity to gain experience is not automatically a paid job, and these categories are search directions rather than promises of vacancies or suitability.

No completion date or job guarantee is assumed. Review progress using independent demonstrations and application feedback, not the number of numbered lessons.
